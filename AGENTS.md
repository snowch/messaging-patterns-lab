# Messaging Patterns Lab

Apply `.agents/skills/ux/SKILL.md` and `.agents/skills/learning-design/SKILL.md` before and after changes. Run every example natively and in actual browser Linux. Never substitute worked output for execution. Distinguish real ZeroMQ mechanisms from authored application policies and durability guarantees. Fast reruns use a warm Linux guest with a fresh process, private scratch filesystem and new user/PID/network/mount/IPC/UTS namespaces for every source execution. Fresh Linux mode starts a new guest each time. Stop and Reset Linux destroy the guest. Test both modes, state isolation, reset and feature fallback; never retry student source after its running marker. Preserve static reading, accessible controls, Pages-relative paths, pinned assets, notices and separate reading marks. Do not claim external connectivity, durable messaging or production benchmarks from these bounded local experiments.
